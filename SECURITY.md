# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting for this repository:

**[Report a vulnerability](https://github.com/glubean/glubean/security/advisories/new)**

You'll get an acknowledgement within 48 hours. Please include reproduction
steps and the affected package(s)/version(s) where possible.

## Supported versions

Only the latest published version of the `@glubean/*` packages receives
security fixes. All packages share one lockstep version, so upgrading any one
of them means upgrading all of them to the same version.

## Scope

This policy covers the code in this repository (the `@glubean/*` npm packages
and the `glubean` CLI). Issues affecting the hosted Glubean Cloud service can
also be reported through the same channel and will be routed appropriately.
